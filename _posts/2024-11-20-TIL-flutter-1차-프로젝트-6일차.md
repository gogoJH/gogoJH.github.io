## 문제 상황

작업 브랜치를 develop에 병합했다가 revert한 뒤, 다시 PR을 작성하자 revert 이후의 커밋 내용만 변경 내역으로 인식되는 문제가 있었습니다.

회원가입 기능을 리팩토링하고 Open API 기반 자동완성을 구현하던 중 발생한 병합 문제였습니다.

## 당시 진행한 처리

1. 별도의 `merge_test` 브랜치를 만들었습니다.
2. 해당 브랜치에서 develop의 병합 이전 커밋을 기준으로 작업 브랜치를 다시 병합했습니다.
3. 나머지 작업도 순서대로 병합한 뒤 `merge_test`로 PR을 작성했습니다.

![당시 병합 문제를 정리한 과정](/img/merge.png)

이 기록은 당시 별도 브랜치에서 구성했던 처리 흐름을 정리한 것입니다.

## 함께 진행한 작업

회원가입 화면 리팩토링과 Open API 검색·자동완성 기능을 진행했습니다.
